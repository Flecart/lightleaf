# Third-party notice: Latex Suite

The snippet engine in this directory (snippet options and matching order, tabstops, autofraction, tabout, matrix
shortcuts, auto-enlarged brackets) reimplements the behaviour of the Obsidian plugin
[Latex Suite](https://github.com/artisticat1/obsidian-latex-suite), and the snippet format and `data.json` settings
are compatible with it. `default-snippets.js` and `default-variables.js` are a user configuration derived from
Latex Suite's default snippets and variables.
